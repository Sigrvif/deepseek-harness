# @deepseek-ai/dsh-client-ui-fork-info

fork(local-test): the "Fork additions" tab in the Plugins settings page —
a static, locale-aware (en/zh) inventory of what this fork carries beyond
upstream, with the billion-context and superpowers attributions.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>
- The inventory is maintained by hand; a new fork addition must update `locales.ts` (both languages) in the same change.
